# CampusLens

Прототип для **LOCUS Startup Hackathon 2026, кейс 01**: визуальный профиль университета.

Абитуриент вводит название вуза и за целевые 30 секунд получает не рекламный буклет, а проверенную подборку фотографий кампуса, общежитий, аудиторий, библиотек и города — с источником, датой и оценкой достоверности.

## Как это работает

1. Поиск вуза в Wikipedia (EN/RU), с разбором неоднозначных запросов вроде `NU` или `КазНУ`.
2. Сбор изображений с Wikimedia Commons по названию вуза, категориям и городу.
3. Отсев логотипов, марок, схем и визуальных дублей.
4. Проверка принадлежности: название вуза/города в файле и категориях Commons.
5. Раскладка по категориям и честные предупреждения, если данных мало.

Сервис **не подменяет** стоковые фотографии под конкретный кампус. Если кадр нельзя подтвердить, он понижается в достоверности или не показывается.

## Стек

- React 19 + TypeScript + Vite
- Wikipedia API и Wikimedia Commons API
- OpenStreetMap (карта кампуса)
- Без бэкенда в этой версии: запросы идут из браузера

## Запуск локально

```bash
npm install
npm run dev
```

Откройте локальный URL из терминала (обычно `http://localhost:5173`).

## Демо на GitHub Pages

После push в `main` сайт собирается и публикуется автоматически:

**https://beknazarberikbosyn-dot.github.io/campuslens/**

Важно: для GitHub Pages в `vite.config.ts` задан `base: '/campuslens/'` при сборке в Actions. Без этого JS/CSS не загружаются и экран остаётся белым.

## Тестовый сценарий для жюри

1. `Nazarbayev University` — полный профиль, лаборатории, кампус, Астана.
2. `КазНУ` или `NU` — должен спросить, какой вуз имеется в виду, либо открыть КазНУ / NU.
3. `University of Oxford` — вуз вне казахстанского демо.
4. Случайный набор букв — честный отказ, без чужого кампуса.
5. Фильтры: общежитие, спорт, лаборатории, студенческая жизнь.
6. Клик по фото — источник, дата, лицензия, объяснение оценки.
7. Кнопка «Сравнить вуз».

## Ограничения прототипа

- Живой поиск зависит от покрытия Wikimedia: у части вузов мало открытых фото общежитий и спорта. Это показывается как нехватка данных, а не заполняется стоком.
- Климат, транспорт и стоимость жизни — ориентиры по городу, не официальная статистика университета. Если города нет в справочнике, блок скрывается.
- Студенческие отзывы в этой версии не симулируются: нет проверяемого корпуса отзывов.
- Демо не ограничено страной, но качество выдачи выше там, где Commons богат кадрами.

## Готовые компоненты

- Шрифты Google Fonts (Fraunces, Manrope)
- Карта через embed OpenStreetMap
- Стартовые обложки на лендинге — реальные файлы Commons, не генерация

## Команда и AI

Прототип собран как рабочий фронтенд-сервис для кейса. AI используется в логике продукта как классификация и оценка достоверности по метаданным источника, не как генерация фейковых фотографий кампуса.
