# CampusLens

Прототип для **LOCUS Startup Hackathon 2026, кейс 01**: визуальный профиль университета.

Абитуриент вводит название вуза и примерно за **30 секунд** получает не рекламный буклет приёмной, а проверенную подборку фотографий кампуса, общежитий, аудиторий, библиотек, лабораторий и города. У каждого кадра есть источник, дата, лицензия и оценка достоверности.

Дополнительно сервис считает рейтинг по отзывам CampusLens, сравнивает два вуза и открывает официальные карточки места в 2ГИС, Google Maps, Яндекс Картах и OpenStreetMap.

**Демо:** [https://beknazarberikbosyn-dot.github.io/campuslens/](https://beknazarberikbosyn-dot.github.io/campuslens/)

Если страница выглядит как старая версия (по 3 отзыва на вуз), откройте [ссылку с обходом кэша](https://beknazarberikbosyn-dot.github.io/campuslens/?v=16) или обновите вкладку через Cmd+Shift+R / Ctrl+Shift+R.

## Что делает продукт

CampusLens отвечает на вопрос: «как на самом деле выглядит этот университет, и чему в выдаче можно верить?»

- Ищет вуз в Wikipedia (EN/RU), в том числе по сокращениям вроде `NU`, `КазНУ`, `MIT`.
- Собирает открытые фото с Wikimedia Commons.
- Отсекает логотипы, гербы, марки, схемы и визуальные дубли.
- Проверяет, что файл относится к этому вузу или городу, а не к случайному кампусу.
- Раскладывает кадры по категориям: кампус, общежитие, аудитории, библиотека, лаборатории, спорт, студенческая жизнь, город.
- Показывает честные предупреждения, если данных мало — без стоковой подмены.
- Считает итоговый балл из фотокампуса и отзывов при сравнении двух вузов.
- Открывает официальные карточки вуза на картах, не копируя чужие тексты отзывов.

Сервис **не генерирует** фотографии кампуса и **не подставляет** сток «похожий на этот вуз».

## Экраны

| Экран | Что происходит |
| --- | --- |
| Главная | Поиск, подсказки по демо-вузам, топ по отзывам |
| Уточнение запроса | Если `NU` или другое сокращение неоднозначно — спрашиваем, какой вуз имелся в виду |
| Сборка профиля | Пошаговый пайплайн с таймером (~30 с) |
| Профиль | Фото, карта OSM, климат/транспорт, отзывы, ссылки на карты, фильтры категорий |
| Сравнение | Два вуза рядом: кадры + отзывы + итоговый балл CampusLens |
| Оценки вузов | Рейтинг, 16 отзывов на демо-вуз, фильтр по роли, форма своего отзыва, проверка исходника на GitHub |
| Честный отказ | Если вуз не найден — не показываем чужой кампус |

## Как это работает

Пайплайн запускается из `src/lib/buildProfile.ts`.

1. **Поиск вуза** (`src/lib/wiki.ts`)  
   Wikipedia API EN/RU. Сокращения разбираются через словарь `ALIASES` в `src/data/catalog.ts`. Если совпадений несколько, пользователь выбирает карточку сам.

2. **Карточка университета**  
   Из Wikipedia берутся описание, координаты, thumbnail и URL статьи.

3. **Сбор фото** (`src/lib/commons.ts`)  
   Wikimedia Commons API: поиск по названию вуза, категориям и городу. SVG и не-изображения отбрасываются сразу.

4. **Карточки на картах** (`src/lib/maps.ts`)  
   Overpass / Photon ищут кампус в OpenStreetMap. Параллельно собираются официальные ссылки на 2ГИС, Google Maps, Яндекс Карты, OSM и Apple Maps.

5. **Отсев и проверка** (`src/lib/verify.ts`)  
   Убираются логотипы, схемы, марки и дубли. Балл достоверности растёт, если в названии, описании или категориях Commons есть имя вуза/города.  
   Пороги: `verified` ≥ 78, `likely` ≥ 58, иначе `uncertain`.

6. **Категории и профиль**  
   Кадры раскладываются по ключам из `CATEGORIES`. Если мало фото общежитий или мало подтверждённых кадров, показывается предупреждение, а не чужая картинка.

Итоговый балл при сравнении (`combinedCampusScore`): отзывы весят примерно половину оценки, если их достаточно; иначе сильнее визуальная часть.

## Отзывы

На каждом демо-вузе лежит **16 отзывов CampusLens** (абитуриент / студент / выпускник) с оценками по кампусу, общежитию, учёбе, студенческой жизни и городу.

| Вуз | Файл корпуса |
| --- | --- |
| Nazarbayev University | [`src/data/seedReviews/nazarbayev.ts`](src/data/seedReviews/nazarbayev.ts) |
| Al-Farabi Kazakh National University | [`src/data/seedReviews/kaznu.ts`](src/data/seedReviews/kaznu.ts) |
| Satbayev University | [`src/data/seedReviews/satbayev.ts`](src/data/seedReviews/satbayev.ts) |
| MIT | [`src/data/seedReviews/mit.ts`](src/data/seedReviews/mit.ts) |
| University of Oxford | [`src/data/seedReviews/oxford.ts`](src/data/seedReviews/oxford.ts) |
| Stanford University | [`src/data/seedReviews/stanford.ts`](src/data/seedReviews/stanford.ts) |

На сайте у каждой карточки есть `id` (`seed-mit-15` и т.д.) и ссылка «найти этот id на GitHub». Текст на странице должен совпадать с файлом в репозитории — так проверяется происхождение корпуса.

Свой отзыв, оставленный в форме, хранится в `localStorage` браузера (`campuslens-reviews-v1`) и помечается отдельно. Бэкенда для отзывов нет.

Сервис **не парсит** страницы 2ГИС, Google Maps и Яндекс Карт: это запрещено их правилами. Живые отзывы карт остаются на официальных карточках по ссылкам рядом.

## Стек

| Слой | Технология | Зачем |
| --- | --- | --- |
| UI | React 19 | Экраны, формы, состояние пайплайна |
| Язык | TypeScript ~6 | Типы профиля, отзывов, фото |
| Сборка | Vite 8 | Dev-сервер и production-бандл |
| Линтер | Oxlint | `npm run lint` |
| Хостинг | GitHub Pages (`docs/`) | Статический сайт после push в `main` |
| CI | GitHub Actions, Node 22 | `npm ci` → `npm run build` → копирование в `docs/` |

**Внешние API (из браузера, без своего бэкенда):**

- Wikipedia API (`en` / `ru`) — поиск и карточка вуза
- Wikimedia Commons API — фото и метаданные (автор, лицензия, дата)
- OpenStreetMap embed — карта кампуса
- Overpass API и Photon (Komoot) — поиск места вуза
- Официальные search-URL 2ГИС, Google Maps, Яндекс Карт, Apple Maps

**Зависимости runtime:** только `react` и `react-dom`. Шрифты — Google Fonts (Fraunces, Manrope).

## Запуск локально

Нужны **Node.js 22+** и npm.

```bash
git clone https://github.com/beknazarberikbosyn-dot/campuslens.git
cd campuslens
npm install
npm run dev
```

Vite поднимется на **http://localhost:5173** (если порт занят — следующий свободный, например 5174). URL смотрите в терминале.

### Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Dev-сервер Vite |
| `npm run build` | `tsc -b` и production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр production-сборки |
| `npm run lint` | Oxlint |

Локально `base` в Vite равен `/`. В GitHub Actions выставляется `GITHUB_ACTIONS=true`, и `base` становится `/campuslens/`, иначе JS/CSS на Pages не найдутся и экран останется белым.

Живой поиск Wikipedia и Commons требует сети. Без сети профиль не соберётся.

## Демо на GitHub Pages

После push в `main` workflow `.github/workflows/deploy.yml`:

1. Ставит зависимости (`npm ci`).
2. Собирает проект с `GITHUB_ACTIONS=true`.
3. Копирует `dist/` в `docs/` и добавляет `docs/.nojekyll`.
4. Коммитит обновлённый `docs/` сообщением `Deploy site to docs/`.

Репозиторий должен быть настроен как GitHub Pages: ветка `main`, папка `/docs`.

## Тестовый сценарий для жюри

1. `Nazarbayev University` — полный профиль, лаборатории, кампус, Астана.
2. `КазНУ` или `NU` — уточнение неоднозначного запроса либо переход к КазНУ / NU.
3. `University of Oxford` — вуз вне казахстанского демо.
4. Случайный набор букв — честный отказ, без чужого кампуса.
5. Фильтры: общежитие, спорт, лаборатории, студенческая жизнь.
6. Клик по фото — источник, дата, лицензия, объяснение оценки достоверности.
7. Кнопка «Сравнить вуз» — второй запрос и итоговый балл.
8. «Оценки вузов» — 16 отзывов на демо-вуз, ссылки на 2ГИС / Google / Яндекс, блок «Как проверить эти отзывы».

## Ограничения прототипа

- Покрытие Wikimedia неравномерное: у части вузов мало открытых фото общежитий и спорта. Это показывается как нехватка данных, а не заполняется стоком.
- Климат, транспорт и стоимость жизни — ориентиры по городу из `src/data/catalog.ts`, не официальная статистика вуза. Если города нет в справочнике, блок скрывается.
- Корпус отзывов — открытые тексты CampusLens, не выгрузка из карт. Проверка: сверка с файлом на GitHub, не паспорт студента.
- Качество выдачи выше там, где Commons богат кадрами. Поиск не ограничен Казахстаном.
- Overpass иногда медленный или недоступен; тогда остаются поисковые ссылки на карты по названию вуза.
- Отзывы с формы живут только в текущем браузере.

## Команда и AI

Прототип собран как рабочий фронтенд для хакатон-кейса. AI в продукте используется как **классификация и оценка достоверности по метаданным источника**, не как генерация фейковых фотографий кампуса.
